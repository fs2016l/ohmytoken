## 免费使用与需要授权的范围

**个人和企业内部使用免费。转售、收费托管，以及以购买付费产品或服务为条件取得软件或使用权，需要许可方事先书面授权。**

| 使用场景                                           | 授权要求                                                                             |
| -------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 个人学习、研究或日常使用                           | 不收取软件许可费                                                                     |
| 公司给员工安装，供内部工作使用                     | 不收取软件许可费，不设员工人数或营业收入门槛                                         |
| 自由职业者使用软件辅助收费项目                     | 不仅因工作获得收入就需要商业授权                                                     |

| 免费分享官方原版或发布修改版                       | 允许，遵守声明、来源和源码提供要求；修改版对外提供时须公开对应完整源码并延续同一许可 |
| 销售原版、修改版、激活码、软件订阅或付费功能       | 需要事先书面授权                                                                     |

## 授权方式

许可方为 `LICENSE` 中列明的 fs2016l，仅在其有权授权的范围内提供授权。官方信息入口为 [Oh My Token 官网](https://ohmytoken.net)。

商业授权须由许可方另行书面确认，并约定被授权主体、适用版本、允许的用途、期限和费用。购买官方服务、付费咨询或自愿捐赠不会自动取得转售、付费捆绑或收费托管权利。

依当前许可证取得商业销售或收费托管授权后，仍须遵守第 5 条的源码公开与相同许可义务，以及版权、来源和第三方声明要求。该授权不自动允许闭源发布修改版，也不覆盖许可方无权授权的第三方材料。
